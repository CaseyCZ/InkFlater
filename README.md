# InkFlater Tattoo

Moderný prezentačný web tetovacieho štúdia InkFlater v Raslaviciach.

## Aktuálna verzia

**0.2.0** – kompletný responzívny redesign.

### Hlavné časti
- výrazný hero s vlastnými fotografiami,
- portfólio s fullscreen galériou,
- predstavenie Adama Kučinského,
- proces od nápadu po tetovanie,
- informácie pre prvé tetovanie,
- FAQ,
- kontakty, Instagram, Facebook a Google Maps,
- lokálne SEO a Schema.org dáta,
- čistý vanilla JavaScript bez jQuery.
